# 第 25 步验收：结果评分

## 范围

本步只实现结果评分，不读取规则遵守、仓位、止损、计划执行或情绪行为，
因此不包含第 26 步执行评分。

## 评分方法（result-v1）

总分为 0–100 的整数：

- 风险调整结果 50 分：R 倍数在 -1R 至 +1R 之间线性映射到 0–50，区间外封顶或保底。
- 计划目标达成 30 分：`max(R, 0) / plannedTargetRMultiple` 映射到 0–30，最高 30。
- 交易结果 20 分：净盈利 20、盈亏平衡 10、净亏损 0。

所有 R 倍数按六位定点数计算，不使用 JavaScript 浮点数参与评分。

## API 和持久化

- `PUT /trades/:tradeId/result-score` 接收 `plannedTargetRMultiple`。
- 省略目标时复用已保存目标；传 `null` 清除计划目标和结果评分。
- 评分前必须先完成交易 P&L/R 分析。
- 重算交易分析会清除旧评分，避免使用过期收益数据。
- 详情接口返回评分、目标、算法版本、计算时间和方法说明。

迁移 `20260728001300_step_25_result_score` 新增计划目标、结果评分、算法版本和
计算时间，并以数据库约束保证目标为正、分数在 0–100、来源字段完整。
