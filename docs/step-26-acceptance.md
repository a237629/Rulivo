# 第 26 步验收：执行评分

## 范围

本步只实现执行评分，不实现第 27 步四象限评价。

## 方法（execution-v1）

五个维度均来自第 17 步有证据的规则结果：

- 规则遵守：日内交易上限。
- 仓位：相对历史中位数的仓位突增。
- 止损：止损是否向扩大风险方向移动。
- 计划：是否遵守分配的 Playbook。
- 情绪行为：亏损后的短时重入。它只是可观察行为代理，不推断用户的内在情绪。

每个维度保持 `PASS`、`FAIL` 或 `UNKNOWN`。执行分为：

`已知维度中的 PASS 数 / 已知维度总数 × 100`

`UNKNOWN` 不进入分母、不记 0 分，也不强判为违规。全部维度未知时，
`executionScore` 为 `null`；响应同时返回覆盖率和逐维度状态。

## API 与一致性

- `PUT /trades/:tradeId/execution-score` 根据当前用户拥有的规则结果计算并保存。
- `GET /trades/:tradeId` 返回分数、覆盖率、逐维度状态、版本和方法说明。
- 规则重新评估后自动清空旧执行分，防止使用过期规则结果。
- 所有接口按认证用户隔离。
