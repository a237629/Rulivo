# 第 28 步验收：AI 主动追问

## 范围

本步只实现基于缺失证据的主动追问，不实现第 29 步自动复盘摘要。

## follow-up-v1

- 问题只来自当前交易规则结果中的 `UNKNOWN` 或 `MISSING_DATA`。
- 固定优先级为止损、计划、仓位、亏损后重入、日内交易限制。
- 每轮只生成一个问题，并返回与问题绑定的快捷选项。
- 用户必须选择一个有效快捷选项，或提供 1–2000 字自由文本；不能同时提交两者。
- 同一证据在同一会话中不会重复询问。
- 每个会话最多三轮，到达限制后状态为 `MAX_ROUNDS`。
- 无缺失证据时直接完成，不生成无意义问题。

回答单独保存为用户证据，不自动篡改规则结果。后续重算规则必须显式消费这些证据，
避免把自然语言答案悄悄转成违规或守规结论。

## API

- `POST /trades/:tradeId/follow-ups` 创建或恢复当前会话。
- `GET /trades/:tradeId/follow-ups/current` 获取最近会话。
- `POST /follow-ups/:sessionId/answers` 提交快捷选项或自由文本并获取下一问。
- 所有接口验证交易及会话归属。

## 数据库

迁移 `20260728001600_step_28_follow_up` 新增会话和轮次表：

- 每笔交易最多一个活动会话；
- 轮次由数据库约束限制在 1–3；
- 已回答轮次必须且只能保存快捷选项或自由文本之一；
- 会话和交易通过 `(trade_id, user_id)` 复合外键保持租户一致。
